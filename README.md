# Paradise Nursery Shopping Application

Paradise Nursery is an online shopping platform for houseplant enthusiasts. This React application allows users to browse various categories of plants, view details, add items to a shopping cart, and manage cart items dynamically using Redux Toolkit.

## Features
- Interactive Landing Page with a background image and Get Started button.
- Categorized product listing (Aromatic, Medicinal, Low Maintenance).
- Dynamic Redux-powered Shopping Cart.
- Quantity adjustment, item deletion, and subtotal calculation in real-time.
